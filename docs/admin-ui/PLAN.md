# خطة توحيد واجهة الإدارة وإزالة التكرار

التاريخ: 2026-11-09. الحالة: نُفّذت محليًا؛ تفاصيل التحقق في [سجل التنفيذ](RESULTS.md).

## الهدف
الحفاظ على توزيع الأدوات المقبول، مع مكان أساسي واضح لكل اختصار ونظام ألوان واحد لصفحات الإدارة، بحيث يكون الوصول مباشرًا ولا تختلط ألوان الإجراءات بحالات النجاح والتحذير والخطأ.

## النطاق
- ضروري: مراجعة قوالب الإدارة، وروابط الشريط العلوي والقائمة والشريط المقابل ودليل الأدوات والتثبيت الشخصي.
- ضروري: توحيد الخلفيات والنصوص والأزرار والتركيز والحالات في الإدارة وصفحات الدخول، مع دعم العربية والإنجليزية والموبايل.
- ضروري: فحص صفحات الإدارة المسجّلة فعليًا، وتوثيق الصفحات والحالات التي أمكن تشغيلها.
- الحفاظ على روابط السجلات داخل الجداول والعودة السياقية؛ إزالة اختصارات التنقل المستقلة المتكررة دون حذف وظائف.
- خارج النطاق: هوية الموقع العام، ألوان المعاينات المختارة بواسطة المستخدم، الصور والرسوم البيانية التي تمثل بيانات، النشر على الخادم.

## التقنية والهيكل
Go templates + CSS variables + JavaScript الموجود. لا إطار عمل جديد.
سجل التنقل المفلتر بالصلاحيات والتفضيلات ← توزيع مركزي للاختصارات دون تكرار URL ← القوالب المشتركة ← مراجعة المتصفح.
ملف ألوان الإدارة المشترك ← جميع صفحات الإدارة ← استثناءات محددة لمعنى الحالة ومعاينات الموقع.

## خطوات التنفيذ
1. [x] **الجرد — S:** حفظ تكرارات الروابط والألوان المعلنة، وحصر الصفحات المتاحة.
2. [x] **ملكية الاختصارات — M:** توزيع الوجهات مركزيًا، واستبعاد ما له مكان في التنقل الأساسي والتثبيت، ومعالجة العرض على الهاتف دون فقدان أداة.
3. [x] **الألوان المشتركة — M:** اعتماد نفس الأسطح والنصوص والإجراء الأساسي في كل الإدارة، واستبدال ألوان الإجراءات المحلية المخالفة بالمتغيرات المشتركة.
4. [x] **الحالات والاستثناءات — M:** فصل النجاح والتحذير والخطأ، والاحتفاظ بألوان المحتوى والمعاينة والبيانات ذات المعنى.
5. [x] **التحقق — M:** اختبارات الصلاحيات والوحدات والتكرار، وتشغيل الصفحات، وقياس التباين، ومراجعة العربية/الإنجليزية وأحجام 320–1440 وتكبير النص.
6. [x] **التوثيق — S:** تحديث DESIGN.md وإضافة سجل التنفيذ والتغطية وصور المراجعة لهذه الخطة.

## المخاطر والقرارات
- الروابط السياقية داخل المحتوى تؤدي وظيفة مختلفة عن اختصار التنقل؛ لا تُحذف لمجرد تطابق وجهتها.
- تغيّر الصلاحيات أو التثبيت قد يغيّر الوجهات المتاحة؛ لا نعتمد على قوائم روابط ثابتة تتجاوز سجل التنقل.
- بعض الصفحات تحتاج بيانات أو إعداد خدمات؛ يُذكر ذلك في تقرير التغطية ولا يُدّعى فحص حالة غير متاحة.
- توجد خطة سابقة في PLAN.md لجوانب أخرى من المشروع؛ تبقى كما هي، وهذه الخطة مستقلة.

## معايير القبول
- لا تتكرر وجهة واحدة بين اختصارات التنقل المستقلة الظاهرة في الصفحة.
- تبقى الأدوات متاحة عند تغيير عرض الشاشة أو التثبيت والصلاحيات.
- مصدر ألوان الأسطح والنصوص والإجراء الأساسي مشترك بين الإدارة، والألوان الدلالية للحالات تحافظ على معناها.
- تباين النصوص العادية المستهدفة لا يقل عن 4.5:1، وحلقة التركيز واضحة.
- لا يظهر تمرير أفقي للصفحة عند المقاسات المفحوصة؛ جداول البيانات الكبيرة تتمرّر داخل منطقتها.
- نجاح الاختبارات المناسبة وتوثيق حدود التغطية الفعلية.

## أول ثلاث إجراءات
1. حفظ جرد الروابط والألوان في docs/admin-ui/.
2. توحيد توزيع الاختصارات في طبقة عرض واحدة بدلاً من شروط مكررة داخل القوالب.
3. توحيد متغيرات الألوان ثم فحص الإعدادات والتصميم والمحرر والاتصالات والصفحات المسجّلة.
