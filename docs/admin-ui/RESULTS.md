# سجل تنفيذ تحسين واجهة الإدارة

2026-11-09 — نُفّذت الخطة محليًا. [الخطة](PLAN.md) · [اتجاه التصميم](../../DESIGN.md)

## التغييرات

- توزيع الاختصارات من مصدر واحد في `internal/httpx/workspace_tools.go`: التنقل الأساسي والتبويبات والتثبيت الشخصي تحجز وجهاتها أولًا، ثم تُوزّع الوجهات المتبقية بين الأعلى والقائمة والشريط المقابل ودليل الأدوات. تُحذف روابط الانتقال الزائدة من ملخصات اللوحة مع بقاء المعلومات والوظائف.
- روابط السجلات والجداول والعودة السياقية تبقى متاحة؛ معيار إزالة التكرار يخص اختصارات التنقل المستقلة.
- أدوات الشريط المقابل تنتقل بنفس عناصرها إلى قائمة «أدوات أخرى» على الهاتف. جرى إصلاح اتجاه فتح القائمة في العربية والتحقق من حدودها في العربية والإنجليزية. عند غياب JavaScript تظل الروابط في مسار الصفحة.
- تغيير التثبيت يُحدّث مناطق التنقل فقط ويحافظ على تركيز الكيبورد. لا يستبدل نموذج التحرير أو بياناته غير المحفوظة.
- ألوان مشتركة للإدارة: خلفية `#f7f8fa`، لوحات بيضاء، نص `#20252b`، نص ثانوي `#626a73`، إجراء أساسي `#246b73`. استُبدلت ألوان الأزرار والتركيز والاختيار المحلية المخالفة، مع إبقاء الأخضر للنجاح والعنبري للتحذير والأحمر للخطأ.
- صفحة إدارة العضوية تستخدم نفس ألوان الإدارة؛ صفحة العضوية العامة وهوية الموقع المحفوظة ومعاينات المحتوى وألوان البيانات ذات المعنى تبقى مستقلة.
- إصلاح رابط الاتصالات في أداة الهوية الذي كان يعرض 404، والتفاف تبويبات الإعدادات على عرض 320px.

## أدلة التحقق

| الفحص | النتيجة |
|---|---|
| زحف صفحات الإدارة عند عرض 1440px | 96 صفحة HTML مختلفة متاحة، دون فشل HTTP أو اختلاف في ألوان الجذر المستهدفة أو اختصارات أدوات مكررة أو تمرير أفقي للصفحة |
| نفس الزحف عند عرض 390px | نفس التغطية والنتيجة |
| مقاسات 320 و768 و1440 | اللوحة والإعدادات العامة وتصميم الموقع والاتصالات وقائمة المقالات |
| العربية والإنجليزية | مراجعة اتجاه اللوحة وحدود قائمة الأدوات على 320 و390px |
| تكبير النص 200% | اللوحة الإنجليزية دون خروج الصفحة عن العرض |
| التثبيت وإلغاء التثبيت | دورتان متتاليتان؛ تعود التبويبات والأدوات المتاحة دون إعادة تحميل يدوي |
| الكيبورد وتغيير العرض | حفظ التركيز بعد تحديث التنقل؛ رجوع الأدوات للشريط عند الانتقال للديسكتوب |
| Go | نجاح اختبارات 9 حزم مرتبطة بالتغييرات |
| JavaScript والصياغة | نجاح node --check للملفات المعدلة وgit diff --check |

ملفا الزحف يحتويان 102 زيارة لكل مقاس: 97 استجابة لصفحات HTML، تشمل وجهة محوّلة مكررة، و5 صور معاينات. لذلك التغطية المعلنة هي **96 صفحة مختلفة**، وليست 102 شاشة.

قياسات التباين للأزواج المشتركة: النص الأساسي 14.52:1، الثانوي 5.16:1، زر الإجراء 6.13:1، النجاح 6.47:1، التحذير 5.75:1، الخطأ 4.73:1. هذه قياسات للأزواج المحددة، وليست شهادة وصول شاملة لكل عنصر في المنتج.

المراجعة المستقلة كشفت فقدان تركيز الكيبورد عند تحديث الاختصارات؛ أُصلح وأعيد اختباره. المراجعة البصرية كشفت فتح قائمة الهاتف خارج الشاشة في RTL؛ أُصلح وأعيد قياس حدودها. استُخدمت إرشادات OpenDesigner والمراجعة الفعلية بالمتصفح؛ لم يُنشأ نظام OpenDesigner افتراضي أو تقييم آلي شامل لغياب state.json للنظام الحالي.

## حدود المراجعة

المراجعة على نسخة محلية ببيانات تجريبية، وليست نشرًا على الخادم. الزحف يغطي صفحات GET التي أمكن الوصول إليها من الروابط؛ لا يثبت حالات كل سجل أو كل خطأ أو إعداد كل موفر خارجي. اختبارات الصلاحيات والوحدات تغطي منطق إتاحة الأدوات، أما جولة المتصفح فبحساب الإدارة التجريبي. لم تُجرَ عمليات حذف أو إرسال أو دفع أو اتصال فعلي بمقدمي الخدمات. ألوان معاينات الموقع والرسوم والعقد والتصنيفات ذات الدلالة ليست ألوان إجراءات الإدارة، ولذلك لم تُوحّد قسرًا.
