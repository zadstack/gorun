# Dashboard decisions

## Compact distributed workspace

Owner feedback: the color-only pass still did not feel professional/clean; the simplified visual direction was accepted, then the owner asked for controls at the top, settings/shortcuts on the left in Arabic, operational tools below the main content, and tighter gaps/padding.

Implemented: quiet neutral surfaces, 12px gaps / 16px panels, one primary action in the top bar, main content with paired counts/analytics, left utility settings/pins/guide, bottom operational summaries. All setup destinations remain available (four common links plus seven under More settings in the fixture). Desktop setup is open; phone setup starts collapsed. Saved personal order uses the flow layout, and reset restores the distributed default.

## Use empty shell areas for direct tool access

Owner clarified that the open space in the search/account bar, lower sidebar, opposite narrow rail and lower work area should reveal tools currently nested inside sections. Implemented named one-click module links from the existing authorized/personalized nav registry in those four areas. Module links keep their canonical names/routes. The dashboard tool directory is a static non-sortable section; dashboard drag handlers ignore it as a drop target. Existing personal widget ordering, the agents modal and language/logout controls remain functional.
